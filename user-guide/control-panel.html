Control Panel (moved to Settings)

Since version 1.10.86 the Control Panel is part of Settings and no longer in the menu. Every button is still there.

#Where everything went

Was in the Control PanelNow in
Computer, Version, Data folder size, Technical detailsSettings → App & updates
Update Software (Update Now)Settings → App & updates
Restart the AppSettings → App & updates
Stop ServerSettings → App & updates
Remove the AppSettings → App & updates
Backup Data (Create Backup)Settings → Data & Backups → Backup files (ZIP)
Restore Backup (Choose Backup ZIP)Settings → Data & Backups → Backup files (ZIP)
Move to Another PC (now Create Backup, then Restore on the new PC)Settings → Data & Backups → Backup files (ZIP)
Open Data Folder, Open Backups FolderSettings → Data & Backups → Backup files (ZIP)
The result panelUnder each card
"Update and backup scripts not found"Settings → App & updates

The green or red dot on the Control Panel's menu button went too: when the app is not running, the app shows its own not running screen instead. See Failed to fetch, App Not Running.
