Install on Linux or a NAS, step by step

Ubuntu, Linux Mint and Debian: install the .deb package like any other program. Any other Linux: the AppImage, one file you double-click. Or paste one line into the Terminal. Each step is explained.

Which guide is mine?

Windows (most PCs and laptops): Install on Windows. Mac (Apple logo top left): Install on a Mac. Linux or a NAS: Install on Linux or a NAS. Already installed? Updating. Wondering whether it is safe? Is it safe? Security and privacy.

#Ubuntu, Linux Mint, Debian: the .deb package

The easiest way. Everything the app needs is inside, including Node.js: nothing else to install.

  1. DownloadOpen the latest release and, under Assets, click free-gst-billing_version_amd64.deb. It goes into your Downloads folder.
  2. Install itDouble-click the file. Software Install (Ubuntu) or Package Installer (Mint) opens: click Install and type the password you use to log in. Or in the Terminal: 
    sudo apt install ~/Downloads/free-gst-billing_*_amd64.deb
  3. Open itOpen your applications menu and click Free GST Billing. The app opens in its own window if you have Chrome, Chromium or Edge, or in your browser otherwise.

Your books (invoices, clients, settings, saved PDFs) are kept in your home folder, in ~/.local/share/free-gst-billing-data. Each person who logs in to the computer has their own. The app answers this computer only.

To update: download the new .deb from the release page and install it the same way. The app says so when a new version is out. Your books are not touched.

To remove the program: sudo apt remove free-gst-billing. Your books stay in ~/.local/share/free-gst-billing-data; delete that folder yourself only if you want them gone.

#Any other Linux: the AppImage

  1. DownloadDownload the AppImage (for 64-bit Intel or AMD computers).
  2. Allow it to run, onceRight-click the file → Properties → Permissions → tick Allow executing file as program. Or in the Terminal: chmod +x ~/Downloads/Free-GST-Billing-Linux-x86_64.AppImage
  3. Double-click itThe app opens. Keep the file somewhere you will find it again, for example your home folder.

Your books are kept in ~/.local/share/free-gst-billing-data, the same folder the .deb uses. To update: download the new AppImage and use it instead of the old file; your books are not touched.

If nothing happens on an older system, it is missing FUSE: run it once from the Terminal with --appimage-extract-and-run after the file name, or install the .deb instead.

#Used the app before? Your earlier books

If you used the ZIP or the one-line install before, the .deb and the AppImage start with empty books and leave the earlier copy exactly as it was. The first time they open, they show where the earlier books are (and keep that note in ~/.local/share/free-gst-billing-data/OLD-BOOKS-FOUND.txt). To bring them across, before you enter anything new:

  1. Stop the new appSettings → App & updates in the app → Stop Server.
  2. Copy the booksPaste the copy command from that note into the Terminal. For the one-line install it is: 
    cp -a ~/.local/share/free-gst-billing/_system/data/. ~/.local/share/free-gst-billing-data/data/
    It copies: the earlier copy keeps its books too.
  3. Open Free GST Billing againYour invoices and clients are there.

Or use the app itself: in the earlier copy, Settings → Data Management → Export Backup, then import that file in the new app.

#On a NAS or home server: Docker

For a Synology, QNAP, TrueNAS or any machine with Docker. The app runs in a container; your books are kept in a Docker volume.

A NAS has no screen, so you open the app from your phones, tablets and PCs on the same network, the same safe way as using it on a phone: every device is paired once with a one-time code and the app's PIN, and the connection is encrypted (HTTPS). Nobody on your network gets in without pairing.

  1. Get docker-compose.ymlDownload it from the latest release into a folder on the NAS.
  2. Choose your PINOpen the file and replace CHANGE-ME in FGSB_PIN: "CHANGE-ME" with a PIN of 6 or 8 digits. In FGSB_PHONE_HOSTS, put the NAS's address as you will type it, for example "192.168.1.50".
  3. Start itIn that folder: docker compose up -d
  4. Get the pairing linkdocker logs free-gst-billing shows a line Pair your first phone, tablet or PC: open https://192.168.1.50:47443/pair#code=.... The code works for 10 minutes; a new one is printed after that, until the first device is paired.
  5. Pair the first deviceOpen that link on the phone or PC. The browser warns Your connection is not private once: see why, and how to check it. Type the PIN and tap Pair this device.
  6. More devicesOn a paired device: Settings → Privacy & Security → Use on phone or tablet → Pair a phone or tablet, and scan the QR code. Remove a device there too.

Docker Desktop on a Windows or Mac PC: the same steps work. Start it with docker compose up -d in the folder with docker-compose.yml, not with Docker Desktop's Run button (that skips the port and the PIN, so the app cannot be opened). Then open https://127.0.0.1:47443/pair on that PC: https, not http, and not http://localhost:47371 (that address works only inside the container). docker logs free-gst-billing says what is missing if it does not open.

After the first start you can delete the FGSB_PIN line: the PIN is kept with the books (change it in App lock). Never forward port 47443 on your router: the app is for your own network, not the internet. To update: put the new version number in the image: line and run docker compose up -d again; the books stay in the volume, and paired devices stay paired. The container runs as an ordinary user, never as root.

#Open the Terminal

Press Ctrl + Alt + T. A window opens where you type commands. New to this? Read Using the Terminal first; it takes two minutes.

To paste a command into the Terminal, use Ctrl + Shift + V (not Ctrl + V), then press Enter.

#Other way: install with one line

  1. Copy this line, paste it into the Terminal, press Enter 
    curl -fsSL https://raw.githubusercontent.com/IamRamgarhia/Free-GST-Billing-Software/main/install.sh | bash
  2. Watch it workIt shows four steps, each ending in OK: [1/4] Checking this computer, [2/4] Downloading (also Node.js, the engine the app runs on, if the computer does not have version 18 or newer; it is kept inside the app folder), [3/4] Installing, [4/4] Adding icons.
  3. Answer one questionOpen Free GST Billing by itself when this computer starts? [y/N]: type y and press Enter, or just Enter for no.
  4. The app opensIn its own window if you have Chrome, Chromium or Edge, or in your browser otherwise.

Every day after that: open Free GST Billing from your applications menu. To update or repair it: run the same line again; your data is backed up to ~/Documents/FreeGSTBill Backups first and never touched.

If it says curl: command not found, run sudo apt install -y curl first. The app goes to ~/.local/share/free-gst-billing; your data is in _system/data inside it.

NAS or Alpine: there may be no bash; end the line with | sh instead. Alpine needs Node.js from its own store first: sudo apk add nodejs. To choose the folder, put FREEGSTBILL_DIR=/volume1/apps/free-gst-billing just before sh.

To remove it (your invoices are kept unless you type DELETE when asked):

curl -fsSL https://raw.githubusercontent.com/IamRamgarhia/Free-GST-Billing-Software/main/install.sh | bash -s -- --uninstall

#Other way: download the ZIP

Install Node.js yourself, then unzip and start the app.

#Step 1: Install Node.js 26

The Node.js in Ubuntu's own store is often too old for the app, so it comes from NodeSource, the official source for Linux. Paste these one at a time, pressing Enter after each:

sudo apt install -y curl unzip
curl -fsSL https://deb.nodesource.com/setup_26.x | sudo -E bash -
sudo apt install -y nodejs

When it asks for your password, type the password you use to log in and press Enter. Nothing appears while you type, not even dots; that is normal.

Check it worked:

node -v

It should print v26, for example v26.13.1 (v22 or newer also works).

Fedora: sudo dnf install nodejs npm. Arch: sudo pacman -S nodejs npm. Alpine / NAS: sudo apk add nodejs npm.

#Step 2: Download and unzip

  1. DownloadDownload Free GST Billing It goes into your Downloads folder.
  2. Unzip itPaste this in the Terminal and press Enter: it unpacks the app into a folder in your home folder. 
    cd ~ && unzip -o ~/Downloads/Free-GST-Billing.zip

#Step 3: Start the app

cd ~/Free-GST-Billing && bash "Free GST Billing - LINUX.sh"
  1. Wait up to a minuteWhen it says Server running, the app opens in your browser at http://localhost:47371. You can close the Terminal; the app keeps running. (A download from before version 1.10.83 first asks Install now? [Y/n]: press Enter.)

Every day after that, open the Terminal and run the same command. Or bookmark http://localhost:47371; it works while the app is running. To stop the app: Settings → App & updates in the app → Stop Server, or restart the computer.

#On a NAS or server (for IT people)

unzip Free-GST-Billing.zip
cd Free-GST-Billing
bash "_system/start-unix.sh"

The ZIP carries the app's packages, so there is no npm install; any Node.js 18 or newer runs it.

The app listens on 127.0.0.1:47371 only. For phones and other PCs, turn on phone and tablet access (pairing, PIN and HTTPS on port 47443); on a server with no screen, start it with FGSB_PHONE_ACCESS=1 and FGSB_PIN=<6 or 8 digits> and pair the first device with the code it prints, as in Docker. Updating from inside the app needs unzip or python3.
